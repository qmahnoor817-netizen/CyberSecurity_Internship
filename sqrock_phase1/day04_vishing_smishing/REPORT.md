# Day 4 — Vishing & Smishing Simulation Report

## Definitions
- **Vishing** (voice phishing): a phone call in which the attacker
  impersonates a trusted party (IT, bank, government agency) to extract
  credentials or push a fraudulent action.
- **Smishing** (SMS phishing): the same tactic over text message,
  usually paired with a shortened link and a tight deadline.

## Three scripts generated (see script output)
1. **IT pretext** — "unusual activity" + password verification request.
2. **Bank pretext** — "suspicious transaction" + fraud-department authority.
3. **Government/SMS pretext** — account-suspension threat with a
   shortened verification link.

## Psychological triggers used
| Trigger | How it appears in the scripts |
|---|---|
| **Authority** | Caller claims to be IT/bank/government staff |
| **Urgency** | "detected unusual activity," "within 2 hours" |
| **Fear** | Threat of account suspension / fraud loss |
| **Scarcity/time pressure** | Countdown-style deadlines |
| **Liking/rapport** | Friendly opener ("Hi, this is Alex") to build quick trust |

These map to Cialdini's principles of influence, which is why
awareness training explicitly calls them out — recognizing the trigger
in the moment is more reliable than trying to "spot the fake" from
tone alone.

## Defender takeaway
Train staff on a **verify-independently** rule: hang up/ignore the
message, then contact the organization using a number or channel you
already know is legitimate — never one provided in the suspicious
call/text itself.
